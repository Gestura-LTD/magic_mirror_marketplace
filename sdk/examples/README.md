# Examples

`io.github.robertoalonsotrillo.glass` -- the mirror's built-in game Glass as a package ("keep one long bow
smooth"): reads `sound.tone`, `sound.signal`, `sound.source`, `sound.source2`, `sound.level`, sends its score and
a noise target, and carries its own font. Try it from the `sdk/` folder:

    python3 check.py examples/io.github.robertoalonsotrillo.glass
    python3 simulator/simulate.py examples/io.github.robertoalonsotrillo.glass

It is one of the group's own packages, so on the mirror it has no "community" frame.
