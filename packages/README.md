# packages/

One folder per game, named after its id; one file per version:

    packages/io.github.yourname.mygame/1.0.0.json
    packages/io.github.yourname.mygame/thumb.png      (optional)

The format is in [../schemas/entry.schema.json](../schemas/entry.schema.json); how to submit is in
[../CONTRIBUTING.md](../CONTRIBUTING.md).
